## area(r) in circle.py
Принимает на вход число r - длина радиус круга
>def area(r)

Возвращаемое значение - число, площадь круга.
Пример вызова:
> def area(3):
>   pi * 3 * 3
> area(3) ≈ 28.2743

## perimeter(r) in circle.py
Принимает на вход число r - длина радиус окружности
>def area(r)

Возвращаемое значение - число, длина окружности.
Пример вызова:
> def area(3):
>   2 * pi * 3
> area(3) ≈ 18.8495
